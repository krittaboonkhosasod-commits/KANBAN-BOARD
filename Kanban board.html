เชื่อมต่อ Google Sheet

📖 คู่มือการใช้งาน

1. เริ่มต้นใช้งาน
  • พิมพ์ ชื่อผู้ใช้งาน แล้วกด “เข้าใช้งาน” (ไม่มีรหัสผ่าน)
  • ข้อมูลแยกตามชื่อผู้ใช้ ครั้งต่อไปให้พิมพ์ชื่อเดิม ให้ตรงทุกตัวอักษร (ตัวพิมพ์ใหญ่-เล็ก และช่องว่างมีผล)
  • ปุ่ม “ออกจากระบบ” ใช้เมื่อต้องการสลับไปใช้ชื่อผู้ใช้อื่น
  • ปุ่ม “⚙ ตั้งค่า” ใช้เชื่อมต่อ Google Sheet และเปิดคู่มือนี้
2. เพิ่มงานใหม่
  1. กดปุ่ม ＋ สีม่วงมุมขวาล่าง
  2. กรอก รายละเอียดงาน เลือกประเภท PM หรือ CM และเลือก วันที่กำหนดส่ง (จำเป็น) เวลาใส่หรือไม่ใส่ก็ได้
  3. พิมพ์ชื่อ ผู้รับผิดชอบ ระบบจะจำชื่อไว้เป็นรายการให้เลือกครั้งต่อไป กด × ข้างชื่อเพื่อลบออกจากรายการ
  4. กด “เพิ่ม” งานจะเข้าคอลัมน์ To Do

ถ้าเลือกวันที่กำหนดส่งที่ผ่านมาแล้ว งานจะเข้า Backlog และมีรายการขึ้นในคอลัมน์ Waiting ให้อัตโนมัติ เพื่อบันทึกหมายเหตุว่าติดอะไรอยู่

3. ย้ายงาน อัปเดตความคืบหน้า และลบงาน
  • แตะการ์ดงานเพื่อเปิดส่วนควบคุม แตะซ้ำเพื่อปิด
  • แถบเลื่อน % ปรับความคืบหน้าทีละ 5% (บันทึกให้อัตโนมัติ)
  • ย้ายไป ▸ ส่งงานไปขั้นถัดไป: Backlog → To Do → In Progress → Done
  • แถว Backlog / To Do / In Progress / Done ในการ์ดที่เปิดอยู่ แตะเพื่อย้ายงานไปสถานะนั้นได้ทันที (ย้ายถอยหลังก็ได้)
  • บนคอมพิวเตอร์ ลากการ์ด ไปวางในคอลัมน์ที่ต้องการได้เลย (ลากเข้า Waiting ไม่ได้)
  • เมื่องานเข้า Done ความคืบหน้าจะเป็น 100% ทันที และแถบเลื่อนจะล็อก
  • ลบ จะลบการ์ดและรายการ Waiting ของงานนั้นด้วย (ไม่มีการถามยืนยัน)
4. ความหมายของคอลัมน์และสี
  • Backlog — งานที่ต้องทำ แต่ยังไม่ได้เริ่มวางแผน
  • Waiting — งานที่ติดรอข้อมูล / รออนุมัติ / รอผู้รับเหมา / รออะไหล่ พิมพ์หมายเหตุในช่องได้ และกด “ลบ” เมื่อเรียบร้อย
  • To Do — งานที่พร้อมดำเนินการ
  • In Progress — งานที่กำลังดำเนินการ
  • Done — งานที่เสร็จแล้ว (การ์ดเป็นสีเขียวอ่อน)
  • ป้ายสีน้ำเงิน PM และสีแดง CM บอกประเภทงาน วงกลมสีคือตัวอักษรแรกของชื่อผู้รับผิดชอบ
  • เวลากำหนดส่งที่เลยแล้วและยังไม่เสร็จ จะเป็นสีแดงพร้อมไอคอนเตือน
5. ตัวเลขสรุปและตัวกรอง
  • การ์ดด้านบนแสดง งานทั้งหมด · กำลังทำ · เสร็จแล้ว (เป็น %) · เลยกำหนด
  • ปุ่ม ทั้งหมด / PM / CM กรองการ์ดในกระดาน (คอลัมน์ Waiting ไม่ถูกกรอง)
6. ส่งออก PNG / PDF / Excel
  • PNG และ PDF บันทึกภาพกระดานทั้งหมดพร้อมชื่อผู้ใช้และวันที่ (PDF เป็นกระดาษ A4 แนวนอน)
  • Excel ได้ไฟล์ kanban.xlsx จัดงานแยกตามสถานะ พร้อมสรุปจำนวนงานและคำอธิบายสถานะ พร้อมพิมพ์

ต้องต่ออินเทอร์เน็ตเพื่อโหลดตัวช่วยส่งออกก่อน ถ้ากดแล้วไม่ทำงาน ให้รีเฟรชหน้าแล้วลองใหม่

7. เชื่อมต่อ Google Sheet (ซิงค์ข้อมูล)
  1. ต้องสร้าง Apps Script ก่อน (ดูโค้ดและขั้นตอนที่หัวข้อ 10) แล้วเปิดปุ่ม “⚙ ตั้งค่า” วาง Web app URL ของ Apps Script (ลงท้าย /exec) ไม่ใช่ลิงก์ของชีตโดยตรง
  2. ใส่รหัสลับ (TOKEN) ถ้ามีตั้งไว้ใน Code.gs ถ้าไม่มีให้เว้นว่าง
  3. กด “ทดสอบการเชื่อมต่อ” ถ้าขึ้น ✓ ให้กด “บันทึก”
  • แต่ละเครื่องตั้งค่าครั้งเดียว หลังจากนั้นข้อมูลจะถูกส่งขึ้นชีตอัตโนมัติ (แท็บ Tasks และ Waiting) และดึงข้อมูลล่าสุดทุก 1 นาที
  • ใช้ชื่อผู้ใช้เดียวกันบนเครื่องอื่น จะเห็นกระดานชุดเดียวกัน
  • ออฟไลน์ก็ใช้งานได้ ข้อมูลจะถูกส่งขึ้นชีตเมื่อกลับมาออนไลน์
  • ครั้งแรกที่เชื่อม งานที่มีอยู่ในเครื่องนี้จะถูกส่งขึ้นชีตทั้งหมดก่อน แล้วจึงดึงข้อมูลจากชีตมารวมกัน
  • “ยกเลิกการเชื่อมต่อ” จะกลับไปเก็บข้อมูลในเครื่องนี้อย่างเดียว

สถานะข้างชื่อผู้ใช้: ☁ ซิงค์แล้ว = เรียบร้อย · ● รอบันทึก / ⟳ = กำลังส่งข้อมูล · ⚠ = ยังส่งไม่ได้ ข้อมูลเก็บในเครื่องไว้ก่อน ตรวจอินเทอร์เน็ตหรือการตั้งค่า

หมายเหตุ: ให้ใช้ Google Sheet คนละไฟล์ กับของ Calendar เพราะแต่ละโปรแกรมใช้โค้ด Code.gs ของตัวเอง

8. ข้อควรรู้ และการแก้ปัญหา
  • ข้อมูลเก็บในเบราว์เซอร์ของเครื่องนี้ หากไม่ได้เชื่อม Google Sheet การล้างข้อมูลเบราว์เซอร์ ใช้โหมดไม่ระบุตัวตน หรือเปลี่ยนเครื่อง ข้อมูลจะหาย ควรส่งออก Excel สำรองไว้เป็นระยะ
  • ระบบไม่มีรหัสผ่าน ใครพิมพ์ชื่อผู้ใช้เดียวกันก็เห็นกระดานชุดเดียวกัน
  • ถ้าสองเครื่องแก้งานเดียวกันพร้อมกัน ค่าที่บันทึกทีหลังจะทับค่าก่อนหน้า
  • ข้อมูลไม่ขึ้นบนเครื่องอื่น: ตรวจว่าเชื่อม Google Sheet แล้ว และพิมพ์ชื่อผู้ใช้ตรงกัน
  • ทดสอบการเชื่อมต่อไม่ผ่าน: ตรวจว่าใช้ลิงก์ /exec และ Deploy เป็น “ทุกคน (Anyone)” แล้ว
  • ลบแถวในชีตด้วยมือได้ แต่ถ้าเครื่องไหนยังมีงานนั้นค้างรอส่ง งานจะถูกส่งกลับขึ้นชีตอีกครั้ง
9. ใช้งานบน iPhone / iPad
  1. เปิดหน้าเว็บด้วย Safari แตะปุ่ม แชร์ → เพิ่มไปยังหน้าจอโฮม จะได้ไอคอนโลโก้เปิดใช้เหมือนแอป เต็มหน้าจอ ไม่มีแถบเบราว์เซอร์
  2. บนมือถือคอลัมน์เรียงต่อกันในแนวนอน ปัดซ้าย-ขวาเพื่อดูแต่ละสถานะ แตะการ์ดแล้วใช้ปุ่ม “ย้ายไป ▸” หรือแถวสถานะแทนการลากการ์ด
  3. กดปุ่ม ＋ มุมขวาล่างเพื่อเพิ่มงาน แผ่นฟอร์มจะเลื่อนขึ้นเหนือคีย์บอร์ดให้อัตโนมัติ แตะพื้นที่มืดด้านบนหรือ “ยกเลิก” เพื่อปิด
  4. ปุ่ม PNG / PDF / Excel บน iPhone จะเปิดหน้าต่างแชร์ เลือก “บันทึกไปที่ไฟล์” หรือ “บันทึกรูปภาพ” ได้เลย

ข้อควรระวัง: Safari กับไอคอนบนหน้าจอโฮมเก็บข้อมูลแยกกัน ข้อมูลที่บันทึกใน Safari จะไม่โผล่ในไอคอน และ Safari อาจล้างข้อมูลของเว็บที่ไม่ได้เปิดใช้นานกว่า 7 วัน แนะนำให้ เชื่อมต่อ Google Sheet (หัวข้อ 7) หรือส่งออก Excel สำรองไว้เสมอ

10. ตั้งค่า Google Sheet ทีละขั้น (มีรูปประกอบ + โค้ด Code.gs)

ทำตามทีละขั้น ใช้เวลาประมาณ 5–10 นาที ไม่ต้องเขียนโค้ดเอง แค่คัดลอกแล้ววาง แตะที่รูปจริงเพื่อดูภาพขยาย (รูปในขั้นตอนที่ 3–8 เป็นภาพตัวอย่างจากโปรแกรม Calendar ซึ่งหน้าจอ Apps Script และหน้าตั้งค่าเหมือนกัน แต่โค้ดและชื่อโปรแกรมอาจต่างจากในภาพ)

1

เปิด Apps Script จาก Google Sheet
สร้าง Google Sheet เปล่าใหม่ (แยกไฟล์จากของ Calendar) แล้วไปที่เมนู ส่วนขยาย (จุด 1) → Apps Script (จุด 2) ต้องเปิดจากเมนูในชีตนี้เท่านั้น เพื่อให้โค้ดผูกกับชีตที่ถูกต้อง

2

คัดลอกโค้ด
กดปุ่มด้านล่าง (ไม่ต้องอ่านหรือแก้โค้ด)

3

วางโค้ดและบันทึก
ในหน้า Apps Script คลิกในช่องโค้ด กด Ctrl+A แล้ว Delete เพื่อลบโค้ดเดิมทั้งหมด จากนั้นกด Ctrl+V เพื่อวาง (จุด 1) แล้วกดไอคอนบันทึก 💾 (จุด 2) จนข้อความ “การเปลี่ยนแปลงที่ไม่ได้บันทึก” หายไป (บน Mac ใช้ Cmd แทน Ctrl) ชื่อไฟล์จะเป็น “รหัส.gs” หรือ “Code.gs” ไม่ต้องเปลี่ยนชื่อ

4

ตั้งรหัสลับ (ไม่บังคับ)
ถ้าอยากกันคนอื่นแอบเรียกใช้ ให้ใส่รหัสระหว่างเครื่องหมาย ' ' เช่น const TOKEN = 'abc123'; แล้วกดบันทึกอีกครั้ง และใส่รหัสเดียวกันในช่อง TOKEN ของโปรแกรม ถ้าไม่ต้องการ ปล่อยว่างไว้ทั้งสองที่

5

สร้างการทำให้ใช้งานได้ (Deploy)
กดปุ่มสีน้ำเงิน การทำให้ใช้งานได้ มุมขวาบน (จุด 1) แล้วเลือก การทำให้ใช้งานได้รายการใหม่

ในหน้าต่างที่เปิดขึ้น ตั้งค่าตามรูป: จุด 1 กดไอคอนเฟือง ⚙ ข้างคำว่า “เลือกประเภท” แล้วเลือก เว็บแอป · จุด 2 “ดำเนินการในฐานะ” = ฉัน · จุด 3 “ผู้ที่มีสิทธิ์เข้าถึง” = ทุกคน (ข้อนี้สำคัญ ถ้าไม่ใช่ “ทุกคน” โปรแกรมจะเชื่อมต่อไม่ได้) · จุด 4 กด ทำให้ใช้งานได้

6

อนุญาตสิทธิ์ (ครั้งแรกครั้งเดียว)
ถ้ามีหน้าขอสิทธิ์ ให้กด ให้สิทธิ์เข้าถึง → เลือกบัญชี Google ของคุณ → กด ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต หน้าจอเตือนนี้เป็นเรื่องปกติ เพราะโค้ดนี้คุณสร้างเอง ยังไม่ได้ส่งให้ Google ตรวจ

7

คัดลอก Web app URL
หลังกด Deploy จะมีหน้าต่างสรุป (หรือเปิดได้จาก การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้) กด คัดลอก ใต้หัวข้อ เว็บแอป (จุด 1) ลิงก์ที่ถูกต้องต้อง ลงท้ายด้วย /exec อย่าใช้ลิงก์ในหัวข้อ “ไลบรารี”

8

วางในโปรแกรมและทดสอบ
เปิด ⚙ ตั้งค่า วางลิงก์ในช่อง Web app URL (จุด 1) กด ทดสอบการเชื่อมต่อ (จุด 2) ถ้าขึ้นข้อความสีเขียว “เชื่อมต่อสำเร็จ ✓” ให้กด บันทึก (จุด 3) ถ้าตั้งรหัสลับในขั้นตอนที่ 4 ให้กรอกในช่อง TOKEN ด้วย

เมื่อแก้โค้ดภายหลัง ต้อง Deploy เป็นเวอร์ชันใหม่: การทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → ไอคอนดินสอ ✏️ → เวอร์ชัน “เวอร์ชันใหม่” → ทำให้ใช้งานได้ ลิงก์ /exec เดิมจะยังใช้ต่อได้ · ถ้าติดปัญหา ดูหัวข้อ 8

แตะที่รูปเพื่อปิด · เลื่อนดูได้
